# Exam Re-Scheduler Application

## Description
The Exam Re-Scheduler is a desktop-based application developed in Python that helps college students manage and organize their exam schedules effectively. The application allows students to input their subjects and exam dates, automatically prioritizes them based on urgency, and displays a live countdown to each exam. It features a clean and user-friendly graphical interface built with Tkinter that makes exam planning simple, organized, and stress-free.

---

## Features

### Feature 1: Subject and Exam Date Input
Allows students to enter their subjects along with their corresponding exam dates. Each entry is validated before being saved to ensure accuracy and completeness.

### Feature 2: Automatic Subject Prioritization
Automatically sorts and ranks all subjects based on their exam dates. Subjects with the nearest exam dates are prioritized first, helping students focus on the most urgent exams.

### Feature 3: Exam Countdown Display
Displays a live countdown in days and hours remaining for each exam. Subjects are color-coded based on urgency — red for urgent, yellow for high, and green for low priority.

### Feature 4: Input Validation
Validates all user inputs before saving. The system checks for empty fields, incorrect date formats, and past dates, displaying clear error messages to guide the user.

### Feature 5: Retake / Clear All
Allows students to reset their session by clearing all saved subjects. A confirmation dialog is shown before clearing to prevent accidental deletion.

## OOP Concepts Implemented

### This project demonstrates core Object-Oriented Programming Principles:
- **Encapsulation** — Each class keeps its data private and exposes only the necessary methods. For example, `Subject` stores name and exam date privately and provides getter methods to access them.
- **Abstraction** — Complex logic such as date validation and countdown calculation is hidden inside dedicated classes like `InputValidator` and `CountdownDisplay`, so the user only sees the result.
- **Single Responsibility** — Every class has one specific job. `PriorityRanker` only sorts subjects, `SessionManager` only handles session reset, and `InputValidator` only validates inputs.
- **Dependency Injection** — The `ExamScheduler` controller receives and uses `InputValidator`, `PriorityRanker`, `CountdownDisplay`, and `SessionManager` as separate components without depending on their internal details.

---

## SOLID Principles Applied
- **Single Responsibility Principle (SRP)** — Each class has one responsibility and one reason to change.
- **Open/Closed Principle (OCP)** — The system can be extended with new features by adding new classes without modifying existing ones.
- **Dependency Inversion Principle (DIP)** — High-level classes interact with lower-level components as independent, replaceable modules.

## Building the Executable (Windows)

To convert the app into a standalone `.exe` file that can be shared and run without Python:

**Step 1 — Install PyInstaller:**
```
pip install pyinstaller
```

**Step 2 — Build the executable:**
```
pyinstaller --onefile --windowed --name "ExamScheduler" exam_scheduler.py
```

**Step 3 — Find your `.exe`:**

The executable will be inside the `dist/` folder. Share `ExamScheduler.exe` with anyone on Windows — no Python installation needed to run it.
